# 上課前的準備清單（學員版）

這份清單請在課前完成。看不懂的地方不用擔心，課前檢查時老師會陪你一起確認。

課前檢查時間、地點及老師聯絡方式，以老師發給你的課程通知為準。

---

## 一、準備好這些東西

- [ ] **一台筆電**（Windows 10／11 或 Mac 都可以）
  - 如果是**公司的電腦**，請先問公司能不能自己安裝軟體。很多公司電腦不能安裝，上課會卡住，建議改用自己的電腦。
  - 上課要帶**充電線**。
- [ ] **一支有 LINE 的手機**，上課前充飽電。
- [ ] **一張可以線上刷卡的信用卡**，用來訂閱 ChatGPT Plus（說明在下面第三步）。

---

## 二、申請這些帳號

每個帳號都請**用同一個 Gmail 申請**，比較不會忘記。

> 💡 密碼請讓瀏覽器幫你記住，或寫在自己的筆記本上。上課最常卡住的地方，就是忘記密碼。

### 1. Google 帳號（Gmail）

- [ ] 已經有 Gmail 就不用另外申請。
- [ ] 用電腦打開 <https://aistudio.google.com/>，用 Gmail 登入，看到畫面就代表成功。
  - 第一次登入時會要你同意使用條款，請按同意。
  - 這裡上課時會拿來申請機器人要用的「鑰匙」，課前檢查時由老師帶你建立，並做一次小測試；只登入成功還不能確認 API 可用。

### 2. LINE 帳號設定（手機上操作）

- [ ] 打開手機 LINE → 主頁 → 右上角齒輪「設定」→「帳號」。
- [ ] 確認「**電子郵件帳號**」已經登記，而且你記得密碼。
  - 沒有登記的話，請在這裡新增一個 Email 和密碼。
  - 上課時要用電腦登入 LINE 官方帳號的後台，會需要這組 Email 和密碼。
- [ ] **建立 LINE 官方帳號（課前檢查時老師會陪你一起做）**
  - 用電腦打開 <https://manager.line.biz/>，用剛剛的 Email 登入，按「建立」。
  - 名稱用你想做的服務，例如「小芳手作甜點」，之後也可以改。
  - 建好之後，用手機加它為好友，收到一則歡迎訊息就成功了。
  - 其他設定**先不用動**，上課時會一步一步帶。

### 3. ChatGPT Plus（付費，一個月）

這是整堂課最重要的工具。上午用它來練習和 AI 合作，下午用它的 **Codex** 功能幫我們建立 LINE 機器人。

- [ ] 打開 <https://chatgpt.com/>，用 Gmail 登入（選「使用 Google 帳號繼續」）。
- [ ] 左下角點自己的名字 →「升級方案」→ 選 **Plus**，完成刷卡。
  - 費用是每月 20 美元，刷卡後大約**新台幣 600～650 元**（依銀行匯率）。
  - 請選 **Plus**，不要選便宜的方案。本課程統一用 Plus；Plus 也有用量限制，課前請看剩餘額度，課中有額度不足的備援方式。
- [ ] 在電腦上安裝 **Codex App**：
  - Windows：打開「Microsoft Store」，搜尋 **Codex**，安裝 OpenAI 出的那一個。
  - Mac：到 <https://openai.com/codex/> 下載。
- [ ] 打開 Codex，用**同一個 ChatGPT 帳號**登入。
- [ ] 回到 ChatGPT 網頁，左下角名字 →「設定」→「資料控管」，把「**為所有人改善模型**」**關閉**。
  - 請一起檢查 ChatGPT 與 Codex 的資料控管選項；選項名稱可能不同，由老師陪你確認。關閉訓練選項不代表對話不留存，課末仍要更換課堂使用的憑證。

> 📅 **記得：**課程結束後一個月會自動續訂。如果不想繼續用，請在扣款日前到 ChatGPT 的「設定 → 帳號 → 管理方案」取消。

### 4. Cloudflare 帳號

這是放我們 LINE 機器人的地方，**免費**，不需要信用卡。

- [ ] 打開 <https://dash.cloudflare.com/sign-up>，用 Gmail 註冊。
- [ ] 到 Gmail 收信，點信裡的連結**完成驗證**。
  - 沒收到信的話，請看一下「垃圾郵件」或「促銷內容」資料夾。
- [ ] 重新登入一次，看到 Cloudflare 的首頁就代表成功。

---

## 三、課前一起試一次

- [ ] 能開啟並另存學員的 DOCX／XLSX；沒有合適工具時先用計算機與紙本完成同一題，不需另外買 Office。
- [ ] 老師陪你確認 Node、Codex 與 Cloudflare Skill 已可用，能開啟本機測試頁並儲存檔案。
- [ ] Cloudflare 授權後，Codex 回報的是你的帳號。
- [ ] Gemini 使用自己的專案與 Key，送一個不含個資的短問題成功，記下可用模型；不要把 Key 傳給老師。
- [ ] 課程頁面可以填寫與複製；兩天使用同一瀏覽器設定檔、同一網址。重要的 FAQ 另存文字檔。

## 四、上課第一天要帶的東西

- [ ] 想一想：**你的 LINE 官方帳號，客人最常會問什麼？**請寫下 5 個問題。
  - 不用寫答案，上課時會請 AI 幫你整理。
  - 可以是真的，也可以是想像的。例如開手作小店、接設計案、幫公司回答廠商問題。
  - **不要寫真實客人的姓名、電話或地址。**

---

## 關於上課會拿到的「鑰匙」

上課時你會拿到幾組很長的英文數字，叫做「鑰匙」（金鑰、Token、Secret）。上課時老師會帶你把它們貼給 AI，讓 AI 幫你把機器人接起來。

只要記得兩件事：

- 不要拍照傳到群組，也不要貼到 Facebook 這類公開的地方。
- 課程最後老師會教你「換一把新鑰匙」，到時候你就會明白它們的用途。

---

## 完成了嗎？

全部打勾以後，請用 LINE 傳一句「準備好了」給老師。卡住可傳錯誤截圖，先遮住金鑰、Token、驗證碼與付款資訊。
